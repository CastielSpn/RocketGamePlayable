# 🚀 Ракетная Игра - Уклонение от Астероидов
![screenshot1](https://github.com/CastielSpn/RocketGamePlayable/blob/main/image.png)
Захватывающая 2D космическая стрелялка, созданная с использованием HTML5, CSS3 и JavaScript с графической библиотекой PixiJS. Управляйте своей ракетой через опасные поля астероидов, стреляйте по препятствиям и выживайте как можно дольше!

## 🎮 Особенности Игры

- **Плавное Управление**: Используйте стрелки клавиатуры или сенсорное управление для навигации ракеты
- **Прогрессивная Сложность**: Скорость игры увеличивается с каждым уровнем
- **Эффекты Частиц**: Красивые анимации взрывов при уничтожении астероидов
- **Поддержка Мобильных**: Сенсорное управление для мобильных устройств
- **Система Уровней**: Переходите на новые уровни, достигая вехи в очках
- **Система Жизней**: Начинайте с 3 жизнями - избегайте астероидов, чтобы выжить
- **Подсчет Очков в Реальном Времени**: Зарабатывайте очки за уничтожение астероидов и выживание

## 🎯 Как Играть

### Управление на ПК
- **← →** Стрелки для движения влево и вправо
- **Пробел** для стрельбы

### Мобильное Управление
- **← →** Сенсорные кнопки для движения
- **🔫** Сенсорная кнопка для стрельбы

### Цель Игры
- Избегайте приближающихся астероидов
- Стреляйте по астероидам, чтобы заработать очки
- Выживайте как можно дольше
- Наберите 1000 очков, чтобы перейти на следующий уровень

## 🚀 Начало Работы

1. Клонируйте или скачайте этот репозиторий
2. Откройте `rocket_game.html` в вашем веб-браузере
3. Начните играть немедленно - установка не требуется!

## 🛠️ Технические Детали

- **Графический Движок**: PixiJS 7.4.2
- **Языки**: HTML5, CSS3, JavaScript (ES6+)
- **Адаптивный Дизайн**: Работает на настольных и мобильных устройствах
- **Без Зависимостей**: Чистые веб-технологии, процесс сборки не требуется

## 🎨 Игровая Механика

- **Движение Ракеты**: Плавное горизонтальное движение с обнаружением столкновений границ
- **Появление Астероидов**: Случайно генерируемые астероиды с различной скоростью
- **Обнаружение Столкновений**: Точное круговое обнаружение столкновений для всех игровых объектов
- **Система Частиц**: Динамические эффекты взрывов с использованием графики PixiJS
- **Прогрессивная Сложность**: Скорость игры и частота появления астероидов увеличиваются с уровнями

## 🎮 Скриншоты Игры

Игра включает:
- Красивый звездный фон
- Детализированный спрайт ракеты с окнами и огнем двигателя
- Реалистичная графика астероидов с вращением
- Плавные эффекты взрывов частиц
- Чистый, современный интерфейс с отслеживанием очков

## 🔧 Настройка

Игра легко настраивается через объект `GAME_CONFIG`:
- Настройте скорость игры, скорость ракеты и скорость пуль
- Измените частоту появления астероидов
- Измените систему подсчета очков
- Настройте прогрессию уровней
